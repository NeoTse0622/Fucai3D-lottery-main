# **A lottery number filter tool for Fucai3D**
## Fucai3D Description：
258为例，01234为小，56789为大，他的形态奇偶为：偶奇偶，大小形态为小大大，012路形态为222；
468奇偶型态为偶偶偶，大小型态为小大大，012路型态为102；
如745大小形态为大小大，奇偶形态为奇偶奇，012路形态112
分出一千注彩票的型态，选号技巧就是杀型态。
## Function Description：

**Double click to run ./dist/YouWang5.exe**

1:生成一千注数据，每一组数据在大小组合，奇偶组合，012组合中的形态进行杀号操作

2: 常用杀号，例如杀奇偶组合中的奇偶偶，偶奇奇，杀大小组合中的，小小小，小大大。杀012路组合的101，012，111

3: 双字杀号，杀两个字的组合，如01，10，56，65

4：组合杀号，杀号码组如146798组成的所有号码，如146，169，116，446

5：包含保号，选定数字1，系统生成所有包含数字1的组合

6：爬虫杀号，把近400期开奖数据导入进去，杀往期数据。
